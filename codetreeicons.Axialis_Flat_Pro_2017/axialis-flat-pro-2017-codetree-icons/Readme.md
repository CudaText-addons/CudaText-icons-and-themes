## Installation

- Download the [ZIP file](http://www.pazera-software.com/cudatext/axialis-flat-pro-2017-codetree-icons/files/codetree.Axialis_Flat_Pro_2017_Code_Tree_Icons.zip) with icons, drop it on the CudaText main window and confirm installation.
- Run CudaText, press **F1**, type `icons code tree` and press **Enter**.
- Select one of the icon sets available on the list and press **Enter**.
- You must restart program for the changes to take effect.
