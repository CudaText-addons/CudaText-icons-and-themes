Retro9-PIX is a family of pixeled icon themes for 
CudaText, handdrawn in Gimp by Xanadu. The family 
includes:

* a set of toolbar icons
* a set of sidebar icons
* a set of project toolbar icons

These icon sets shall be combined with the Retro9 
UI theme from Xanadu.

Correction in 2026/11: 4 icons were added by Z.ai:
locate, recents, sessions, star.
