
# Google Material Design toolbar icons for the CudaText editor

## Info

The icons are available in 41 colors and five sizes (16x16, 18x18, 20x20, 24x24, 32x32 pixels).
Colored icons were obtained by converting black PNG icons using the [ImgConvert](http://www.pazera-software.com/products/img-convert/) program, using switches: `--channel-red`, `--channel-green` and `--channel-blue` with proper values of the color channels.

---

## Installation


- Install the **Config Toolbar** plugin (if it is not installed): select menu `Plugins --> Addon Manager --> Install...` Type `plugin config` toolbar, press **Enter** and confirm installation.
- Download the [ZIP file](http://www.pazera-software.com/cudatext/google-material-design-toolbar-icons/files/toolbartheme.Google_Material_Design_Icons_ALL.zip) with icons, drop it on the CudaText main window and confirm installation.
- Select menu `Plugins --> Config Toolbar --> Choose icons of main toolbar...`
- Select one of the icon sets available on the list and press Enter.
- You must restart program for the changes to take effect.
